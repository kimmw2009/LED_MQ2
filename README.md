# MQ2 센서값 맞추기 게임

# 팀원 : ○○○

## 무엇을 만들었나

MQ2 가스 센서의 값을 측정해 현재 값보다 높은 목표값을 정하고, 센서값을 목표값에 가깝게 맞추는 게임을 만들었다.

## 어떤 부품으로

* 라즈베리파이 피코 2 W
* MQ2 가스 센서 / WS2813 LED

## 어떻게 연결했나

| 부품  | 피코 핀 |
| --- | ---- |
| MQ2 | GP27 |
| LED | GP16 |

## 어떻게 작동하나

1. MQ2 센서의 현재 값을 측정한다.
2. 현재 값보다 높은 목표값을 정한다.
3. 센서값을 목표값에 가깝게 만들면 성공한다.
4. LED로 목표값과의 차이를 표시한다.
5. 게임이 끝난 후 `다시`를 입력하면 새 게임을 시작한다.
